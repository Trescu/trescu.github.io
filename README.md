# trescu.github.io

Nyilvános GitHub Pages oldal a **Neptune – nem hivatalos böngészőbővítményhez**.

## Fájlok

- `index.html` – nyilvános kezdőoldal
- `neptune-privacy.html` – Chrome Web Store-hoz használható adatvédelmi tájékoztató
- `styles.css` – közös megjelenés
- `neptune-icon.png` – hivatalos Neptune projektikon

## Chrome Web Store Privacy Policy URL

A GitHub Pages publikálása után:

`https://trescu.github.io/neptune-privacy.html`

## GitHub Pages

A repository legyen nyilvános, majd a GitHubon:

**Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**

A publikálás néhány percet igénybe vehet.
